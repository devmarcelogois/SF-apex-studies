# Apex/SF_interface exercises

A collection of Apex programming exercises created while learning Salesforce development. The repository 
focuses on core language features, common programming patterns and problem-solving using Apex.

## Topics covered

- Collections (`List`, `Map`, `Set`);
- Loops and conditional statements;
- Data filtering and aggregation;
- Sorting algorithms;
- Input validation;
- Duplicate detection;
- Batch processing;
- Lookup relationships;
- SOQL query simulation;
- Bulkification principles.

## You will find: Repository Structure

├── Q1 - Count records by stage
├── Q2 - Filter and sort leads
├── Q3 - Account validation
├── Q4 - Total amount by account
├── Q5 - Remove duplicate contacts
├── Q6 - Create batches
├── Q7 - Query accounts by industry
├── Q8 - Contacts by account industry
└── Q9 - Sum opportunities by account

## Purpose

The goal of this repository is to practice Apex programming through small, focused exercises
that reinforce core concepts and common Salesforce development patterns 

## Technologies

- Apex
- Salesforce Platform
- Developer Console
